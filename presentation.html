API Layer • Data Persistence • AI/ML Processing

Three-Layer Request Processing

🌐 API Layer (FastAPI)
HTTP request handling, validation, routing, response formatting
Stack: FastAPI 0.136 + Uvicorn, Pydantic v2
💾 Data Persistence (SQLite + ChromaDB)
Relational storage, queue management, vector embeddings
Stack: SQLite + aiosqlite, ChromaDB (HNSW)
🤖 AI/ML Layer (Services)
Sentiment scoring, embeddings, semantic search, LLM inference
Stack: VADER + RoBERTa, sentence-transformers (MiniLM), Ollama / Mistral

POST /chat: Three-Layer Architecture

API Layer: Receives question, validates input, calls service, returns JSON response
Data Persistence: ChromaDB semantic search finds similar past entries; SQLite fetches full text + mood scores
AI/ML Layer: Embeddings encode the question; LLM (Ollama) generates answer using retrieved context

POST /reflect — Request & Response

Generate a weekly reflection using LLM 

POST /reflect?start=2026-06-17&end=2026-06-24 HTTP/1.1
Accept: application/json
HTTP/1.1 200 OK
Content-Type: application/json

{
  "narrative": "Over this week, you've experienced a strong positive trajectory with sentiment scores averaging 0.82. Key themes include accomplishment from project completions and consistent productivity throughout the week.",
  "avg_mood": 0.82,
  "entry_count": 7,
  "window": {
    "start": "2026-06-17",
    "end": "2026-06-24"
  }
}

POST /reflect — Aggregation & LLM Generation

1. Data Aggregation: Fetch all entries within the date range, compute average mood score and sentiment distribution
2. Semantic Search: Find emotionally similar past entries using ChromaDB vector search for context
3. LLM Reasoning: Generate narrative reflection using Ollama with aggregated data and similar entry examples
